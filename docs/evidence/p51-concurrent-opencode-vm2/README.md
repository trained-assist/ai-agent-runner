# Два настоящих OpenCode одновременно под разными идентичностями (ai-agent-runner#51)

Закрывает последнюю открытую строку #51 — «два настоящих OpenCode Run одновременно».
Раньше строка была открыта: граница (#51) и lifecycle (#52) доказывались движком
`fake`, а настоящий OpenCode в параллельном прогоне не проверялся.

## Проба нашла дефект — и он исправлен здесь же

Первые два прогона падали: второй ра�� получал
`ISOLATION_IDENTITY_UNAVAILABLE — slot "ta-agent-2" is not a unix account on this host (exit 0)`.

Причина — гонка `'exit'` против stdio в `resolveSlot`: `'exit'` приходит сразу после
смерти процесса, а `'data'` на `stdout` могли ещё не сработать. `getent` отдаёт 70 байт
и выходит за ~1 мс, поэтому на загруженном event loop (два рана стартуют одновременно)
буфер `out` оставался пустым и слот честно читался как отсутствующий unix account.

Исправление — PR [#70](https://github.com/trained-assist/ai-agent-runner/pull/70):
`exitCodeAndDrain` ждёт `'close'` самого процесса, которое приходит строго после
`'exit'` и после закрытия обоих stdio-потоков. Слушаем процесс, а не потоки: у потоков
`'close'` мог случиться до подписки, и промис зависал бы.
